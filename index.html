Quake Radar is no longer live

This page used to show a world map of earthquakes built from public USGS feeds and refreshed every 30 minutes. The project has been archived: the schedule is off and nothing here updates anymore.

It was never an official alert system. For current earthquake information, go to the source.

  • USGS Earthquake Hazards Program → Live official data — the same feeds this dashboard consumed.
  • LLM Radar → Same pipeline, still live: public API → Python → Quarto → GitHub Pages, no server.
  • Source code on GitHub → Public and read-only. Still runs locally if you clone it.
