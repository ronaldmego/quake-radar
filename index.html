How this dashboard works — automated, open-source data delivery

Quake Radar is a live, open-source demo of automated data delivery: raw public data in, a polished self-updating dashboard out — with zero server and zero cost.

The pipeline (fully open, auditable): 
USGS GeoJSON API  →  Python (pandas + great-tables)  →  Quarto dashboard  →  GitHub Pages
        \____________ refreshed every 30 min by GitHub Actions (cron) ____________/
  • No server, no cost, no API key. The USGS feeds are public; a GitHub Actions cron re-fetches, re-renders and redeploys every 30 minutes.
  • Verifiable by design. Every number traces back to the public source cited in the Source footer on each page (USGS, with a link to its documentation) and to the open code.
  • Open methodology. The code that fetches and transforms the data is on GitHub; fork it, read it, reuse it.
